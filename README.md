# Hierro

App web (PWA) para anotar pesos del gimnasio. Funciona sin internet y se instala en Android y PC.

## Funciones
- Ejercicios propios (músculo, equipo, rango de reps, descanso, unilateral)
- Rutinas por split: Arnold, Arnold × U/L, PPL, PPL × U/L, Upper/Lower, Full Body, Bro split o personalizada
- Entrenamiento en vivo: kg y reps por serie, lo que hiciste la última vez, superseries, drop sets, calentamiento, unilaterales por lado
- Sugerencia de peso (doble progresión) y temporizador de descanso
- Historial en calendario, volumen semanal y por músculo, progreso por ejercicio
- Modo oscuro, exportar/importar (JSON y CSV)

## Desarrollo
```bash
npm install
npm run dev
```
